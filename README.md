# 🎮 Luweng Arcade

Selamat datang di **Luweng Arcade**! Sebuah koleksi mini-game *arcade* bergaya retro yang dibuat khusus dari hati. Game ini terinspirasi dari hewan-hewan kesayangan di rumah, khususnya keluarga kucing peliharaan: **Sisi, Tiger, Oyen, Boy, Tiny**, dan tentu saja si kaki seribu ikonik, **Luweng**!

Game ini pada awalnya didedikasikan untuk **Tiger**, yang sedang berjuang keras melawan penyakitnya (FLUTD). Semoga game ini bisa menjadi penyemangat dan hiburan bagi kita semua.

---

## ✨ Fitur Utama
* 📵 **100% Offline:** Dimainkan lancar tanpa koneksi internet (semua *resource*, aset, dan *font* sudah dilokalkan).
* 🕹️ **6 Mini-Games Spesial:** Enam jenis game berbeda dengan mekanik permainan yang unik.
* 🛍️ **Sistem Toko & Koin Global:** Kumpulkan koin dari semua game untuk membuka total **90 karakter unik** (15 karakter per game!).
* 🎵 **Retro BGM & SFX:** Musik dan efek suara 8-bit bergaya klasik.
* ⚡ **Sistem Fisika Realistis:** Menggunakan *Matter.js* untuk benturan dan gravitasi yang mulus.
* 📱 **Web-to-App Ready:** Dibangun menggunakan HTML5 murni yang dibungkus rapi menjadi aplikasi Android (APK/AAB).

---

## 🎮 Daftar Mini-Games

1. 🐛 **Adventure of Luweng**
   Arahkan Luweng memakan dedaunan hidup di berbagai bioma unik. Jangan sampai menabrak batu atau menggigit badan sendiri! Kumpulkan koin dan buka skin evolusi Luweng.
   
2. 😻 **Hungry Sisi**
   Sisi punya perut karung! Tangkap semua makanan lezat yang jatuh dari langit, manfaatkan jam pasir (*slow-mo*) dan magnet. Awas bom dan jamur beracun! 

3. 😹 **Oyen Fishing**
   Bantu Oyen memancing di berbagai ekosistem laut. Tiap karakter Kapten punya stat unik (Kekuatan 💪, Kecepatan ⚡, Keberuntungan 🍀) untuk menghadapi monster laut.

4. 😸 **Tiger Run**
   Game *endless runner* dengan perspektif pseudo-3D. Bantu Tiger berlari, melompat, dan meluncur melewati rintangan sambil dikejar preman kucing.

5. 😼 **Boy Hunting**
   Puzzle asah otak (*Sokoban*). Bantu Boy menangkap buruannya dengan cara mendorong kotak kardus ke air untuk membuat jembatan.

6. 😾 **Tiny Angry**
   Game ketapel fisik (*slingshot*) ala Angry Birds. Gunakan 15 komandan tempur dengan berbagai *skill* (meledak, membelah diri, dash) untuk menghancurkan pertahanan tikus curang!

## 🛠️ Teknologi yang Digunakan
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
* **Physics Engine:** [Matter.js](https://brm.io/matter-js/) (Untuk Tiny Angry)
* **Build Tool:** Web-to-App wrapper
